# 50 - Proxmox VE

[Proxmox](https://proxmox.com/en/) is an open-source virtualization platform that combines KVM-based virtual machines and LXC containers under one management interface. It includes built-in tools for clustering, storage, networking, and backup, making it well-suited for data centers and home labs alike. The web-based GUI and REST API provide centralized control over multiple hosts, while integration with technologies like Ceph and ZFS enables high availability and scalable storage management.
